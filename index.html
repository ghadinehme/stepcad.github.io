StepCAD: Mesh-to-CAD Code Generation via LLM Policy and Geometry-Guided Search

Ghadi Nehme, Faez Ahmed
Massachusetts Institute of Technology
Paper arXiv Code 🤗Model Dataset

StepCAD turns a mesh (grey) into an editable CadQuery program (blue): a policy writes the program one operation at a time while looking at what it has built, and a geometry-guided search then fixes what is still off with local edits.

Abstract

Recovering executable CAD programs from 3D meshes is challenging due to the compositional nature of CAD construction and the interaction between discrete modeling choices and continuous parameters. Many learning-based methods predict complete programs in a single pass and rely predominantly on sketch-extrude representations, limiting operation diversity and opportunities to correct geometric errors during reconstruction.

We introduce StepCAD, a generative optimization approach that combines a state-conditioned CAD policy with geometry-guided search. Given an input mesh, the policy predicts construction actions conditioned on both target and intermediate geometry, and an IoU-guided tree search refines the resulting program through local edits. We also introduce ARCADE, a large-scale dataset of executable CAD programs spanning diverse operations, long construction sequences and dense intermediate states.

Experiments across multiple CAD reconstruction benchmarks show that StepCAD achieves state-of-the-art geometric reconstruction accuracy with consistently high validity, with particularly large gains on complex shapes.

Method

I

Π-StepCAD: a policy conditioned on intermediate geometry

A Qwen2.5-Coder-1.5B policy writes the CadQuery program one operation at a time. At every step it sees the target point cloud and the point cloud of the shape built so far (both encoded by a shared Point-MAE), predicts the next operation, and the CAD kernel executes it.

II

Geometry-aware program search

A beam search (K = 2) walks the program in execution order and tries four local edits at every operation: refine parameters, edit sketch (profile sliced from the mesh), complement cut and skip operation. Candidates are executed and ranked by IoU against the input, so the cost stays linear in program length.
